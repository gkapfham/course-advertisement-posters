# Fonts

The poster uses local font files so it renders identically offline and in print.

| Font | Use | License | Source |
| --- | --- | --- | --- |
| Space Grotesk | Display / headlines | SIL Open Font License 1.1 | <https://fonts.google.com/specimen/Space+Grotesk> |
| Inter | Body copy | SIL Open Font License 1.1 | <https://fonts.google.com/specimen/Inter> |
| Ubuntu Mono | Labels, code, tape symbols | Ubuntu Font Licence 1.0 | <https://fonts.google.com/specimen/Ubuntu+Mono> |

The `.woff2` files are the Latin subsets downloaded from Google Fonts.
`space-grotesk.css` is the original Google Fonts stylesheet kept as a reference.
