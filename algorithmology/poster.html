CMPSC 202 Spring 2025 An Algorithmology course

ALGORITHM ANALYSIS

Where theory meets timing.

Measure what software really costs. Prove the worst-case growth of algorithms, then benchmark data structures and Python programs with reproducible doubling experiments. Build hash tables, trees, queues, and graphs; run projects, skill-checks, and team all-hands studies; and gain the career-ready skills of a practicing algorithm engineer.
