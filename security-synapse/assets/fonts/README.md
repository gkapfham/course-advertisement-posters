# Fonts

The poster uses local font files so it renders identically offline and in print.
Nothing here is fetched from the network at build time.

| Font | Use | License | Source |
| --- | --- | --- | --- |
| Chakra Petch | Display / headlines, wordmark | SIL Open Font License 1.1 | <https://fonts.google.com/specimen/Chakra+Petch> |
| Inter | Body copy | SIL Open Font License 1.1 | <https://fonts.google.com/specimen/Inter> |
| Ubuntu Mono | Labels, chips, schedule, code | Ubuntu Font Licence 1.0 | <https://fonts.google.com/specimen/Ubuntu+Mono> |

The `.woff2` files are the Latin subsets downloaded from Google Fonts, so the
poster can be rendered offline by headless Chromium.

- `chakra-500.woff2`, `chakra-600.woff2`, `chakra-700.woff2` — Chakra Petch
  Medium, SemiBold, and Bold.
- `inter-latin.woff2` — Inter variable, weights 100–900.
- `ubuntu-mono-400.woff2`, `ubuntu-mono-700.woff2` — Ubuntu Mono Regular and
  Bold.
